# Day 8 - Tuples and Indexing

## 📌 Description

This program demonstrates how to create a tuple and access its elements using both positive and negative indexing.

## 💻 Program

```python
colors = ("green", "red", "blue", "yellow", "orange", "black")

print(colors)
print(colors[0])
print(colors[2])
print(colors[5])
print(colors[-1])
print(colors[-3])
```

## ✅ Sample Output

```
('green', 'red', 'blue', 'yellow', 'orange', 'black')

green
blue
black
black
yellow
```

## 📚 Concepts Learned

- Tuple
- Positive indexing
- Negative indexing
- print()

## 🎯 Key Takeaways

- Tuples store multiple values.
- Positive indexing starts from `0`.
- Negative indexing starts from `-1`.
- `-1` always refers to the last element.
