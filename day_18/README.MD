# Day 18 - Simple ATM Program 💳

## Description

This is a simple ATM program created using Python.

The program starts with a balance of ₹10,000 and asks the user to enter their name.

After that, the user can choose different ATM operations from a menu.

## Features

- 👤 Enter user's name
- 💸 Withdraw money
- 💰 Deposit money
- 💳 Check current balance
- 🚪 Exit the program
- 🔄 Menu repeats until the user chooses Exit
- ❌ Shows an error message for an invalid option
- ⚠️ Checks whether enough balance is available before withdrawal

## Menu Options

```text
1. Withdraw the Amount
2. Deposit the Amount
3. Check Balance
4. Exit
