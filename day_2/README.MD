# Day 2 - Variables and print()

## 📌 Description
This program demonstrates how to create a variable and print its value using the `print()` function.

## 💻 Program

```python
name = "Sai eswar"

print("I am", name)
```

## ✅ Output

```
I am Sai eswar
```

## 📚 Concepts Learned

- Variables
- Strings
- print() function
- Printing multiple values using commas

## 🧠 Explanation

- A variable stores data.
- `name` is a variable that stores the string `"errorythm_"`.
- `print("I am", name)` prints the text `"I am"` followed by the value stored in the variable `name`.

## 🎯 Key Takeaways

- Variables help store information.
- Strings are written inside double (`""`) or single (`''`) quotes.
- The `print()` function displays output on the screen.
- Multiple values can be printed using commas inside `print()`.
