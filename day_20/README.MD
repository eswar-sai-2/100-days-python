# Day 20 - QR Code Generator

## Description
This Python program generates a QR code from any text or URL entered by the user.

## Concepts Learned
- import module
- qrcode library
- User input
- Creating QR codes
- Saving image files
- Displaying images

## How to Run

1. Install the library:

pip install qrcode[pil]

2. Run the program:

python QRcode.py

3. Enter any text or URL.

The QR code will be saved as `qr.png`.

## Example

Input:
https://github.com

Output:
A QR code image named `qr.png` is generated.
