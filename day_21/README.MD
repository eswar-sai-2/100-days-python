## 💡 Project

I created a simple **Fingerprint Scan Simulation** using Python.

The program:
1. Displays a fingerprint scan message.
2. Waits for the user to press Enter.
3. Shows different scanning steps.
4. Uses `time.sleep(1)` to create a delay between each step.
5. Displays "Access Granted" at the end.
