# Day 24 - BMI Calculator 🧮

## Description

This is my Day 24 project from my 100 Days of Python journey.

I created a simple BMI Calculator using Python.

The program takes the user's:
- Weight in kilograms
- Height in meters

Then it calculates the BMI and displays the result.

## BMI Formula

BMI = Weight / Height²
