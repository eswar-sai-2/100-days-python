# Day 25 - Typing Speed Test ⌨️

## 📌 Description

This is my Day 25 project from my 100 Days of Python journey.

I created a simple Typing Speed Test using Python.

The program gives the user a sentence to type and calculates:
- ⏱️ Time taken
- ⌨️ Typing speed
- ✅ Whether the sentence was typed correctly

## 🛠️ Concepts Learned

- `import time`
- Variables
- `input()`
- `print()`
- `time.time()`
- `len()`
- Arithmetic operations
- `round()`
- `if` and `else`
- String comparison

## 💡 How It Works

1. The program displays a sentence.
2. The user presses Enter to start.
3. The timer starts.
4. The user types the sentence.
5. The timer stops.
6. Python calculates the time taken.
7. Python calculates typing speed.
8. The program checks whether the typed sentence is correct.
