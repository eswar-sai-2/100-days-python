# 🌳 Recursive Tree using Python

A simple Python project that draws a tree using **Turtle Graphics and Recursion**.

## 📌 Description

The program creates a tree by drawing a main branch and recursively creating smaller branches on both sides.

The recursion stops when the branch length becomes less than 10.

## 🧠 Concepts Used

- Python Turtle
- Functions
- Parameters
- `if` condition
- `return`
- Recursion

## ▶️ How to Run

```bash
python mini_turtle_tree.py
