🎯 4-Digit Number Guessing Game

A simple Python guessing game where the computer generates a random 4-digit number and the player tries to guess it within 10 attempts.

🧠 Concepts Used
random module
random.randint()
while loop
if / elif / else
User input
Input validation
Counters
break
continue
⚙️ How It Works
Computer generates a random 4-digit number.
User enters a 4-digit guess.
The program gives hints:
⬆️ Too low
⬇️ Too high
The player gets 10 attempts.
The game ends when the number is guessed or all attempts are used.
