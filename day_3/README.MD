# Day 3 - User Input

## 📌 Description

This program takes the user's name and age as input and displays a greeting message.

## 💻 Program

```python
name = input("Enter your name: ")
age = int(input("Enter your age: "))

print("Hello!", name)
print("You are", age, "years old.")
```

## ✅ Sample Output

```
Enter your name: Sai Eswar
Enter your age: 20

Hello! Sai Eswar
You are 20 years old.
```

## 📚 Concepts Learned

- input() function
- int() function
- Variables
- Strings
- Integers
- print() function

## 🎯 Key Takeaways

- `input()` is used to get input from the user.
- `int()` converts a string to an integer.
- Variables store user input.
- `print()` displays the output.
