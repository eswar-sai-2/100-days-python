# 📊 Student & Expense Analyzer

A beginner-friendly Python application for managing student marks and personal expenses.

## 🚀 Features

### Student Management
- Add students
- View student records
- Calculate average marks
- Find passed students
- Find the class topper
- Generate a student marks summary

### Expense Management
- Add expenses
- View expenses
- Calculate total expenses
- Find the highest expense
- Delete expenses

### Data Storage
- Save student records using JSON
- Save expense records using JSON
- Load saved data when the application starts

## 🛠️ Technologies Used

- Python
- JSON
- File Handling
- Exception Handling
- Python Modules

## 🧠 Python Concepts Practiced

- Lists and Dictionaries
- List and Dictionary Comprehensions
- Lambda Functions
- `map()`, `filter()`, and `zip()`
- `*args`
- Functions and Modules
- `try` and `except`
- File Handling
