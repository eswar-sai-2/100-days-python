# Day 4 - Addition of Two Numbers

## 📌 Description

This program takes two numbers as input from the user and prints their sum.

## 💻 Program

```python
n1 = int(input("Enter first number: "))
n2 = int(input("Enter second number: "))

total = n1 + n2

print("Sum =", total)
```

## ✅ Sample Output

```
Enter first number: 15
Enter second number: 25
Sum = 40
```

## 📚 Concepts Learned

- input() function
- int() function
- Variables
- Arithmetic operator (+)
- print() function

## 🎯 Key Takeaways

- `input()` reads data from the user.
- `int()` converts a string into an integer.
- The `+` operator is used for addition.
- `print()` displays the output.
