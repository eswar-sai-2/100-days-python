# Day 5 - Basic Calculator

## 📌 Description

This program takes two numbers as input and performs addition, subtraction, multiplication, division, floor division, and power

## 💻 Program

```python
n1 = int(input("enter first value:"))
n2 = int(input("enter second value:"))

print("All answers like addition, subtraction, multiplication, division, floor division, power")

print("Addition : ", n1 + n2)
print("Subtraction : ", n1 - n2)
print("Multiplication : ", n1 * n2)
print("Division : ", n1 / n2)
print("Floor Division :", n1 // n2)
print("Power : ", n1 ** n2)
```
