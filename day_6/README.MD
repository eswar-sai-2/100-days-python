# Day 6 - Even or Odd Number

## 📌 Description

This program checks whether a number entered by the user is even or odd using the `if-else` statement.

## 💻 Program

```python
num = int(input("Enter a number: "))

if num % 2 == 0:
    print("The number", num, "is Even.")
else:
    print("The number", num, "is Odd.")
```

## ✅ Sample Output

```
Enter a number: 8
The number 8 is Even
```

## 📚 Concepts Learned

- input() function
- int() function
- Variables
- if statement
- else statement
- Modulus operator (%)
- Comparison operator (==)

## 🎯 Key Takeaways

- `%` returns the remainder after division.
- Even numbers leave a remainder of `0` when divided by `2`.
- Odd numbers leave a remainder of `1`.
- `if-else` helps a program make decisions.
