# Day 7 - Python Data Types

## 📌 Description

This program demonstrates the basic data types in Python and displays each variable's type using the `type()` function.

## 💻 Program

```python
# Data Types

name = "Sai eswar"
age = 19
cgpa = 8.15
is_student = True

print("Name :", name)
print("Age :", age)
print("CGPA :", cgpa)
print("Student :", is_student)

print(type(name))
print(type(age))
print(type(cgpa))
print(type(is_student))
```

## ✅ Sample Output

```
Name : Sai eswar
Age : 19
CGPA : 8.15
Student : True

<class 'str'>
<class 'int'>
<class 'float'>
<class 'bool'>
```

## 📚 Concepts Learned

- Comments (`#`)
- Variables
- String (`str`)
- Integer (`int`)
- Float (`float`)
- Boolean (`bool`)
- `type()` function

## 🎯 Key Takeaways

- Strings store text.
- Integers store whole numbers.
- Floats store decimal numbers.
- Booleans store `True` or `False`.
- `type()` helps identify the data type of a variable.
