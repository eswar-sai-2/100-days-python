# 📝 Task Manager (Python)

A simple command-line Task Manager built using Python. This project allows users to add, view, and delete tasks through a menu-driven interface.

## 🚀 Features

- ➕ Add new tasks
- 📋 View all tasks
- 🗑️ Delete tasks by task number
- ❌ Exit the application

## 🛠️ Technologies Used

- Python 3

## 📂 Project Structure

```
task_manager.py
README.md
```

## ▶️ How to Run

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the program:

```bash
python task_manager.py
```

## 📖 Menu

====== TASK MANAGER ======
1. Add Task

3. Delete Task
